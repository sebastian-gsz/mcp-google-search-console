### TEXTO COMPLETO: Announcing web multimodal Search performance reporting in Search Console
Home Search Central Google Search Central Blog Send feedback Announcing web multimodal Search performance reporting in Search Console Thursday, September 24, 2026 Understanding how users find your content is crucial for any publisher or site owner. As Search evolves to include more visual and multimodal experiences, we want to ensure you have the data you need to analyze your performance. Today, we are excited to introduce Search Console reporting for web multimodal search, in the report for performance on Search results as well as in the report for Generative AI features . This update is designed to give you insights into how your content is surfaced when users search using images (such as with a smartphone camera). The data reported here includes searches with Lens, Circle to Search on Android, image uploads to Google Search, and the Chrome right-click "Search this image" feature. To view these insights, use the new multimodal search type filter in the performance reports. Click "Export" to download the data and analyze it in your other tools. We believe this new data will help you better understand your site's performance in the modern search landscape and optimize your visual content. The integration of multimodal search data is rolling out globally starting today. You will start seeing these metrics in your Performance report if your site is receiving traffic from these queries. As always, we value your feedback: please let us know what you think via the "Submit feedback" link in Search Console or in the Google Search Central Community .
